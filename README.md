# EXP--TRJ001

64D 意味軌跡における κ ベース幻覚検出と Neural ODE 後処理の検証。

事前登録型（pre-registration）の実験リポジトリ。**仮説・指標・停止規則を凍結してから採取を開始する**方式で運用する。

## 現在のステータス

| 項目 | 状態 |
|---|---|
| 実験計画書 | `docs/EXP-2026-NVS-001_v1.2.md`（凍結候補 / **未凍結**） |
| 凍結マニフェスト | `freeze/FREEZE_MANIFEST.md`（ハッシュ未記入） |
| Phase | Phase 0（仕様凍結）進行中 |

**凍結条件**: `freeze/FREEZE_MANIFEST.md` の全ハッシュ欄が埋まり、そのコミットに `v1.2-frozen` タグが付与された時点で凍結成立。それ以前の生成データは本実験の結果として採用しない。

## ディレクトリ構成

```
docs/        実験計画書・変更履歴
freeze/      凍結マニフェスト（成果物のSHA-256）
configs/     生成設定・プロンプト定義・分割定義
src/         採取・κ計算・評価コード
data/        採取データ（.gitignore 対象。DVC 等で外部管理）
results/     評価結果（図表・ログ）
```

## 運用規則

1. **計画書の変更は凍結タグ以前のみ**。凍結後の変更は新バージョン（v2.0）として別実験扱いとし、v1.2 の結果は v1.2 の規定どおり報告する。
2. **採取後に判定基準・特徴量・閾値を変更しない**。変更が必要と判明した場合は探索的分析として明示的に区別する。
3. すべての成果物（W、μ、コード、プロンプト）は SHA-256 を `freeze/FREEZE_MANIFEST.md` に記録する。
4. 停止規則（計画書 §8）が発動した場合、その時点で実験を終了する。ゲート未通過は失敗ではなく結果である。
