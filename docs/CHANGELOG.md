# CHANGELOG — EXP-2026-NVS-001

## v1.3（凍結候補・未凍結）

- **T1** Type B 用プロンプトの予算欠落を修正。v1.2 では 1,000 件の全枠が
  Type A（fictional_*）で占められ、§5.1/§5.2 で規定した Type B に対応する
  プロンプト予算が存在しなかった。Type A とは独立した別枠として 200 件を新設し、
  Phase 1 の mixed 率ゲートには算入しないと明記。

  実装が組織内に見当たらなかったため、フォールバックを設けず、検出範囲外の
  残存リスクを評価ログに記録する規定に差し替え。

## v1.2（凍結候補・未凍結）

- **G1** PCA を上位 128 成分に拡張。主解析 PC1–64、アブレーション PC4–67。v1.1 の 64 成分凍結では PC1–3 除去アブレーションが実行不能だったため。
- **G2** プロンプト総数 900 → 1,000 件。Phase 1 の 100 件を Phase 2 から除外すると最悪ケース必要数 833 件に対し 33 件不足していたため。Phase 1 プロンプトの再利用を禁止と明記。
- **G3** v1.1 で消失した H1 / H3 の手続き（マスク率 20/35/50%、外挿 20%、不連続系の生成規則）を §7.4 として復活。λ・GP のハイパラ選択がこの手続きに依存するため。
- **G4** λ を補間 MSE で選ぶことの帰結を「事前登録された限界」として明記。
- **G5** Holm 補正のファミリーを分離（F-Primary / F-Layer / F-Exploratory）。
- **G6** アブレーション用プロンプト ID の確定タイミングを明記（Phase 2 生成開始前）。
- **G7** ストレージ見積りを追記（約 5 GB）。
