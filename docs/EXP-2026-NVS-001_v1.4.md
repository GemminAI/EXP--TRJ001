## 6. Phase 3：生軌跡での評価（Gate 3）— 実測結果（探索的、confirmatory ではない）

> 本節の数値は本文書冒頭の警告のとおり、事前登録の裏付けがない**探索的（exploratory）結果**
> として扱うこと。統計的手続き自体（クラスタブートストラップ・Holm補正等）は v1.3 §6.1–6.3 の
> 規定を踏襲していると見られる（証跡: 原稿 v3.3 の記述）。

### 6.1〜6.2 実測（`docs/Paper/FREEZE_MANIFEST.md`、n=496、Layer 16、98プロンプト×8、T<20除外288）

| 指標 | 値 |
|---|---|
| PROP-κ（PCA 64D）Test AUROC | 0.7806（95%CI [0.7298, 0.8232]） |
| BL-LEN Test AUROC | 0.8077（95%CI [0.7632, 0.8475]） |
| PROP-κ vs BL-LEN Δ | −0.0271（95%CI [−0.0727, 0.0190], p=0.869） |
| Gate 3 条件1（AUROC>0.5, p<0.01） | PASS（CI下限 0.730） |
| Gate 3 条件2（Δ>0, p<0.05） | **FAIL**（CI下限が0を含む） |
| **Gate 3 総合判定** | **FAIL** |

### 6.3 アブレーション（実測）

| ID | 結果 |
|---|---|
| ABL-1（生3584D、n=496） | AUROC 0.8472、vs BL-LEN Δ=+0.0395（95%CI [0.0114,0.0726], p=0.004、有意） |
| ABL-2（PC4–67、n=496） | AUROC 0.7969、vs BL-LEN Δ=−0.0108（95%CI [−0.0490,0.0271], p=0.694、有意差なし） |

**Rule 1 分岐の適用について（`docs/Paper/FREEZE_MANIFEST.md` 末尾の注記を継承）**: v1.3 §6.3 の
分岐条件は「64D で AUROC≈0.5 だがアブレーションが有意」を前提とするが、実測の PCA 64D AUROC
（0.7806）は 0.5 に近くなく、単独でも 0.5 を有意に上回る（Gate 3 条件1 PASS）。したがって
この分岐条件の前提そのものを厳密には満たさない——事前登録が想定していなかったパターンである。
ABL-1 が BL-LEN を有意に上回る一方 PCA 64D 単体では Gate 3 条件2 が FAIL するという結果は、
「軌跡に信号がない」のではなく「64D への線形射影が長さ交絡を上回る κ 由来の情報の一部を失って
いる可能性」を示唆する、事前登録の想定外の結果として記録するにとどめる。
