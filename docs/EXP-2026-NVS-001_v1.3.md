## 1. 認識論的定式化（Epistemic Tagging）

事後の解釈変更および指標の選択バイアス（p-hacking）を防ぐため、前提と仮説を事前に凍結する。タグはプロジェクト標準（Definition / Axiom / Conjecture / Experiment / Theorem）に準拠する。

### 1.1 Axiom（仮定・要検証）

- **Axiom 1**: LLM の内部状態が描く 64D 意味軌跡は、C² 級の連続なベクトル場 `dz/dt = f(z)` によって近似可能である。
- **Axiom 2（修正不変量）**: 意味空間の動態は保存系（ハミルトン系）ではなく、アトラクタに収束する散逸系としてモデル化される。したがって保存則の強制（`Loss_Physics`）は用いず、構造的事前分布（`Loss_Prior`）を正則化として用いる。
- **Axiom 3（射影の識別性）**: §2.3 で凍結する射影 W は幻覚に関する識別情報を保持する。§6.3 のアブレーションにより独立に検証する。

### 1.2 Conjecture（仮説）

| ID | 内容 | 位置づけ |
|---|---|---|
| **H0** | 生の 64D 軌跡から算出した κ 特徴量による幻覚検出 AUROC は、応答長のみを特徴量とするベースライン `BL-LEN` を有意に上回る | **Gate 3 通過条件** |
| **H2** | Neural ODE 後処理を経た κ 系列による幻覚検出 AUROC は、Raw および GP ベースラインを有意に上回る | **主要エンドポイント** |
| H1 | 欠損補間および外挿の MSE において、Neural ODE が GP を有意に下回る | 副次 |
| H3 | 生成系が C² 級平滑性の前提から乖離した不連続系であっても、Neural ODE は壊滅的劣化を起こさない | 副次（頑健性） |

主要エンドポイントは **H2 のみ**。H1・H3 の結果によって H2 の採否を左右させない。

### 2.2 時間軸と対象層

- **主時間軸**: 生成時のトークン位置 `t ∈ [1, T]`。

- **副次解析層**: Layer 8、Layer 24（§7.3 の層ファミリーとして Holm 補正）。

#### Layer 16 採択の根拠（Conjecture）

1. 初期層（1–8）は表層的な構文処理が支配的で、事実性・確信度といった高次表現が未発達。
2. 終盤層（24–32）は unembedding へ向けた確率的縮約が働き、軌跡が局所的に急激な跳躍を起こしやすい。Axiom 1 の平滑性前提を損なう恐れがある。
3. 中間層は概念検索・事実統合の information hub として報告されており、幻覚発生時の内部不安定性が曲率として最も純粋に現れると期待される。

> 本根拠は Conjecture であり確立事実ではない。したがって Layer 8 / 24 を副次登録し、層選択の当否自体を検証可能にしている。

層深さ方向の軌跡解析は本実験の対象外（EXP-2026-NVS-002 に分離）。

### 2.3 射影 W の学習と凍結（G1・G6）

| 項目 | 値 |
|---|---|
| キャリブレーションコーパス | 本実験と完全に重複しない独立 200 プロンプト（`configs/calibration_prompts_v1.json`） |
| 射影手法 | 主成分分析（PCA） |
| 算出対象 | Layer 16 の隠れ状態集合（全トークン）から中心化ベクトル μ ∈ R^4096 と**上位 128 成分**の変換行列 W ∈ R^(4096×128) |
| 保存次元 | **128D**（PC1–128） |
| 主解析に使用 | **PC1–64**（これを 64D 意味軌跡と定義する） |
| アブレーションに使用 | PC4–67（§6.3） |
| 凍結 | W と μ の SHA-256 を `freeze/FREEZE_MANIFEST.md` に記録 |

> **G1 の理由**: v1.1 は上位 64 成分のみを凍結していたが、§6.3 の massive-activations アブレーションは PC4–67 を要求する。64 成分しか持たなければ PC65–67 が存在せず、射影後データからの復元も不可能で、アブレーションが実行不能になる。W は凍結・ハッシュ対象であり後から成分を追加できないため、Phase 0 時点で 128 成分まで確保する。追加ストレージは §2.6 のとおり軽微。

#### PCA 採用の根拠

線形射影では時間微分と射影が可換（`d/dt (W h(t)) = W dh/dt`）であるため、射影後の空間における力学系として κ(t) が well-defined になる。非線形射影ではヤコビ行列が干渉し、射影関数自体の歪みが曲率に混入する。

> **注意（誇張しないこと）**: 線形射影は曲率を**保存しない**。部分空間外の成分を落とすため、射影後の κ は元の 4096D の κ の近似ではなく、別個に定義された量である。本実験が測るのは「射影後の力学の曲率」であり、その識別性は Axiom 3 として §6.3 で検証する。

## 3. κ の定式化（Gram 行列式形式）

### 3.1 一般化曲率

3 次元の外積ベース曲率は d ≠ 3, 7 で未定義であるため、Gram 行列式による一般化形を採用する。

離散系列 `z(t) ∈ R^64`（PC1–64）に対し、中心差分で速度・加速度を定義する。

```
v(t) = ( z(t+1) - z(t-1) ) / 2
a(t) = z(t+1) - 2 z(t) + z(t-1)

G(t)     = [[ <v,v>, <v,a> ], [ <a,v>, <a,a> ]]
det G(t) = ||v||^2 ||a||^2 - <v,a>^2
κ(t)     = sqrt( det G(t) ) / ( ||v(t)||^3 + ε )
```

- `ε = 1e-8` に固定。
- 端点 `t = 1, T` は κ 未定義として除外。
- **系列長制限**: `T < 20` のサンプルは Class E として解析対象外。除外率とラベル別内訳を報告する。

### 3.2 パラメータ化

インデックス時間（トークン位置）によるパラメータ化を採用する。弧長パラメータ化は用いない（トークン間の意味的移動速度の変化そのものを特徴量として残すため）。この選択は事後変更を禁止する。

## 4. 特徴量設計

### 4.1 κ 由来特徴量

| 特徴量 | 定義 |
|---|---|
| `kappa_mean` | κ(t) の平均 |
| `kappa_max` | κ(t) の最大値 |
| `kappa_p95` | κ(t) の 95 パーセンタイル |
| `kappa_std` | κ(t) の標準偏差 |
| `spike_rate` | `(1/(T-2)) Σ 1[κ(t) > θ]` |
| `kappa_auc_density` | κ(t) の総和 ÷ (T-2) |

θ は **Train split の κ(t) 分布の 90 パーセンタイル**として決定し、Val / Test に固定適用する。

### 4.2 長さ正規化

総和型・カウント型の特徴量は使用しない。すべて系列長で正規化した密度・率として定義する。

### 4.3 ベースライン分類器

| ID | 特徴量 | 役割 |
|---|---|---|
| `BL-LEN` | 応答長 T のみ | 長さ交絡の検出器（H0 の比較対象） |
| `BL-NORM` | ‖z(t)‖ の統計量（平均・最大・標準偏差） | ノルム由来信号の分離 |

## 5. Phase 1・2：データ採取

### 5.1 幻覚の型

| 型 | 内容 | 判定 | 区分 |
|---|---|---|---|
| Type A（捏造） | 存在しない実体について実質的に記述 | 構成的確定 | **主解析** |
| Type B（事実誤り） | 実在概念に対する誤り | Wikidata 照合 | 副次解析 |
| Type C（棄権） | "I don't know" 等 | 定型文パターン | 第3クラス（除外） |
| Type D（ヘッジ） | "might be", "unclear" 等 | 確率表現パターン | 第4クラス（分離感度分析） |

Type A と Type B は別々に解析し、単一ラベルに統合しない。

### 5.2 ラベル判定器

- 判定対象言語は英語に限定。
- **Type A 陽性**: 架空エンティティへの問いに対し、Type C / D に該当せず実質的記述を展開した応答。
- **Type B 陽性**: 正規化（小文字化・空白除去・記号除去）後、正解集合と不一致かつ Type C / D でないもの。数値の許容誤差規則を `refusal_patterns_en.json` と同梱の照合規則に明記。
- **Class E（判定不能）**: `T < 20`、生成エラー、判定例外。発生率とラベル別内訳を必ず報告する。
- 判定コードは凍結・ハッシュ記録し、採取開始後の変更を禁止する。

### 5.3 プロンプト設計（G2・T1・T2）

**Type A 用プロンプト（主解析対象、1,000 件）**

5 テンプレートに均等分散（各 200 件）。

- `fictional_movie` / `fictional_person` / `fictional_paper` / `fictional_chemical` / `fictional_location`
- mixed 率較正（§5.4）の対象。Phase 1・Phase 2 の予算はこの 1,000 件から充当する。

**Type B 用プロンプト（副次解析対象、200 件・別枠、T1）**

- 実在する概念（映画・人物・化学物質・地名等、Type A と対応するドメインを推奨）について、事実の正誤を問う質問を 200 件用意する。ドメイン内訳は Type A の 5 テンプレートに準拠し各 40 件を目安とする（総数維持を優先し、内訳の均等性は必須としない）。
- 正解集合（`configs/typeB_reference.json`）を Phase 0 で確定し、出典とスナップショット日時を記録する。
- **Type A の 1,000 件とは完全に独立した予算**であり、Phase 1 の mixed 率ゲート（§5.4）には算入しない。Type B は Phase 2 開始時に全件を一括採取し（8 サンプル/プロンプトの同一プロトコルを適用）、Phase 3 では Type A の主解析と並行して副次解析として報告する。
- Type B にはパイロット較正フェーズを設けない。プロンプト数が固定（200 件）であるため、mixed 率が低くても追加生成は行わない。有効陽性数が不足した場合はその旨を結果に明記し、検出力不足として扱う（Type A の Phase 2 逆算式による規模調整の対象外）。

**実在衝突チェック（Type A 用、T2）**

- 実装: Wikipedia API（MediaWiki `action=query`、`missing` フラグ検出）による自動照合。レート制限対応クライアントは既存資産（組織内 `stage1_ingest.py` 相当）を再利用してよい。
- **Google Custom Search 等の第二照合手段は本実験では実施しない**（組織内に既存実装がなく、新規導入のコストが本実験のスコープに見合わないため）。
- 上記の帰結として、Wikipedia に記載のない実在エンティティ（マイナーな地名・非英語圏の人物等）を誤って架空と判定するリスクが残る。この残存リスクを評価ログ（`results/collision_check_log.md` 等）に明記し、「100% 検証」とは記載しない。
- Type B は実在確定済みの概念を選定する工程であり、本チェックの対象外。

**Leave-one-template-out 評価**

Type A の 5 テンプレートについて副次指標として実施（§7.3）。Type B はテンプレート横断比較の対象としない。

### 5.4 段階的採取と Phase 1 ゲート（G2）

**Phase 1（パイロット）**

- 100 プロンプト × 8 サンプル = 800 生成。
- ゲート指標: **mixed プロンプト率**（8 サンプル中に陽性と陰性が共存するプロンプトの割合）。
- 通過条件: mixed 率 ≥ 30%。
- 同時に mixed プロンプト内陽性率と分散を実測する。

**Phase 2（本採取）**

- **Phase 1 で使用した 100 件は Phase 2 から除外する**（較正に用いたプロンプトの再利用は選択効果を生むため）。残り 900 件が上限。
- 必要プロンプト数を実測値から逆算する。

```
M = 1000 / ( mixed_rate × 8 × pos_rate_in_mixed )
```

- 最悪ケース（mixed 率 0.30、mixed 内陽性率 0.50）で M = 833 ≤ 900 となり在庫内に収まる。
- M が 900 を超える場合は、目標有効陽性数を 1,000 から引き下げるのではなく、**プロンプトを追加生成して衝突チェックを通す**こと（目標値の事後引き下げは禁止）。

### 5.5 交絡排除

- 各プロンプトから temperature 0.8 で 8 サンプル生成。
- 8 サンプルが全陽性または全陰性となったプロンプトは主解析から除外し、感度分析に回す。
- 主解析は mixed プロンプト内での陽性 vs 陰性の比較として行う。

## 6. Phase 3：生軌跡での評価（Gate 3）

### 6.1 手続き

1. 生の 64D 軌跡から κ(t) を算出し `PROP-κ` を構成。
2. Logistic Regression（`StandardScaler` 適用、L2）。正則化強度 `C ∈ {1e-3, 1e-2, 1e-1, 1, 10, 100}` を **Validation split** で選択。
3. **プロンプト単位のクラスタブートストラップ**（2,000 回リサンプル）により AUROC の 95% 信頼区間と p 値を算出する。DeLong 検定は用いない（同一プロンプト由来 8 サンプルが独立でないため、区間が過小に出る）。

### 6.2 Gate 3 通過条件（H0）

以下の**両方**を満たすこと。

1. `PROP-κ` の AUROC のクラスタブートストラップ 95% 信頼区間下限が 0.5 を上回る（p < 0.01）。
2. `PROP-κ` と `BL-LEN` の AUROC 差のクラスタブートストラップ 95% 信頼区間下限が 0 を上回る（p < 0.05）。

補助として、応答長でマッチングした部分集合における AUROC を感度分析として報告する。

### 6.3 アブレーション

| ID | 内容 | 目的 |
|---|---|---|
| ABL-1 | 事前指定 200 プロンプトの 4096D 軌跡から直接 κ を算出し AUROC を比較 | Axiom 3（射影による情報損失の有無）の検証 |
| ABL-2 | PC1–3 を除去した **PC4–67** による 64 次元射影での AUROC を比較 | massive activations / rogue dimensions が上位 PC を占拠している可能性の検証 |

**分岐判定**: 64D で AUROC ≈ 0.5 だが ABL-1 または ABL-2 が有意な場合、「軌跡に信号がない」のではなく「射影設計の問題」と判定し、§8 Rule 1 の特例分岐（射影再設計）へ移行する。

PCA の寄与率（PC1–128 の累積寄与率、および PC1–3 の占有率）を必ず記録する。

## 7. Phase 4：後処理の比較（Gate 3 通過時のみ）

### 7.1 主要エンドポイント

Neural ODE 後処理後の κ による幻覚検出 AUROC が、Raw（M0）および GP（M4）を有意に上回ること。プロンプト単位クラスタブートストラップ、p < 0.05、Holm 補正。

### 7.2 比較対象とハイパーパラメータ決定

全手法について、後処理後の曲線を**元の整数トークングリッド `t ∈ [1, T]` 上で再サンプルしてから** κ を再計算する。異なる解像度での評価は禁止する。

| ID | 手法 | ハイパーパラメータ決定規則 |
|---|---|---|
| M0 | Raw | なし |
| M1 | 線形補間 | なし |
| M2 | 3 次スプライン | 平滑化パラメータを Validation の補間 MSE 最小化で選択 |
| M3 | カルマンスムーサ | プロセス/観測ノイズ比を Validation の補間 MSE 最小化で選択 |
| M4 | GP（RBF） | カーネル長さスケール・ノイズを Validation の補間 MSE 最小化で選択 |
| M5 | Neural ODE ＋ `Loss_Prior`（2 階微分ペナルティ） | λ ∈ {1e-4, 1e-3, 1e-2, 1e-1, 1} のうち Validation の補間 MSE を最小化するものを選択 |

**全手法で同一の選択基準・同一の split を用いる**（片方だけ有利な調整を防ぐため）。

#### 事前登録された限界（G4）

`Loss_Prior` は 2 階微分 a を罰する一方、κ の分子は a の速度直交成分そのものである。すなわち提案手法の正則化項は、主要指標に使う量を直接抑制する。

λ を補間 MSE で選ぶ本規定は、**主要エンドポイント（AUROC）で調整しないという p-hacking 回避のための選択**である。その帰結として、H2 が不成立となった場合に「λ を AUROC 基準で選べば勝てた可能性」は否定できない。この限界を事前に記録し、結果報告時に後付けの再選択を行わない。λ 感度曲線（λ ごとの AUROC）は探索的分析として報告してよいが、H2 の判定には用いない。

### 7.3 統計処理と多重比較ファミリー（G5）

| ファミリー | 比較 | 補正 |
|---|---|---|
| F-Primary | M5 vs M0、M5 vs M4 | Holm（2 比較） |
| F-Layer | Layer 16 vs Layer 8、Layer 16 vs Layer 24（Phase 3 で実施） | Holm（2 比較） |
| F-Exploratory | M1〜M3、LOTO、λ 感度、型 B、感度分析 | 補正なし。**確証的主張に用いない**と明示 |

ファミリーをまたいだ補正は行わない。F-Primary の結論は F-Layer / F-Exploratory の結果に依存しない。

### 7.4 副次指標の手続き（G3・復活）

λ・GP ハイパラ選択がこの手続きに依存するため、Phase 0 で凍結する。

**H1（補間・外挿）**

- **補間**: 各軌跡の内部トークンから 20% / 35% / 50% の 3 水準をランダムにマスク。マスク生成は `mask_seed = 20260912` で決定論化し、全手法に**同一のマスクパターン**を適用する。
- **外挿**: 末尾 20% を除去し、前 80% から予測。
- 指標: 64 次元にわたる MSE。Validation でのハイパラ選択、Test での報告。

**H3（Misspecification Test）**

- 合成軌跡に人工的な不連続（ジャンプ）を注入して劣化度を測る。
- **真値の生成系は提案手法の制約族の外から取る**（区分的定数＋ジャンプ、区分的線形など）。C² 級の滑らかな系から生成すると循環論法になるため禁止。
- 指標: 復元 MSE、およびジャンプ位置近傍での誤差集中度。

## 付録 A：明示的に排除した設計

1. **`Loss_Physics` 残差低減の成果指標化** — 自ら課した制約の残差が最適化後に減るのは自明であり循環論法。成果指標から完全に除外。
2. **制約族内から生成した合成データによる検証** — 提案手法の仮定と同じ族から真値を作ると不当に有利。H3 では制約族外の不連続系を必須とした。
3. **保存則（ハミルトニアン・エネルギー保存）の導入** — 意味軌跡は散逸系である可能性が高く理論的根拠がない（Axiom 2）。
4. **「PINN」呼称** — 既知の支配方程式が存在しないため、本手法は Neural ODE / Latent SDE。正則化項は `Loss_Prior` と呼称する。
5. **人手による定性判定** — スケーラビリティと客観性のため、構成的に自動確定できるラベルのみ採用。
6. **DeLong 検定** — クラスタ構造（同一プロンプト 8 サンプル）に対して独立性仮定が破れるため、クラスタブートストラップに置換。
7. **λ の AUROC 基準選択** — 主要エンドポイントでの調整に当たるため禁止（§7.2 の限界記載を参照）。
